How do I get an access token?
  1. Open github.com, click your profile picture, then Settings.
  2. Scroll down and click Developer settings, then Personal access tokens, then Fine-grained tokens.
  3. Click Generate new token and type any name.
  4. Under Repository access pick Only select repositories and choose your portfolio repository.
  5. Under Permissions, open Repository permissions and set Contents to Read and write.
  6. Click Generate token, copy it, and paste it in the Access token box above.

The token stays only in this browser. Never share it with anyone.
